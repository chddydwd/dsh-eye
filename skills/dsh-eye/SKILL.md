# dsh-eye：怎么"看"这块屏幕

dsh-eye 是 DSH 插件：后台常驻采样，最近约 45 秒画面躺在内存里（不写盘）；可选留档把缩略图写进插件目录的 archive/。它**不会动手**——只报坐标、只出图，点不点由你/用户决定。

## 0. 先判断：真的需要看图吗

| 用户的问法 | 用什么 | 成本 |
|---|---|---|
| "这上面写的什么字"、"这段报错是什么" | eye_text | ≈0（无障碍树；读不到才回落 OCR） |
| "那个按钮在哪"、"输入框在哪" | eye_find | ≈0（只给屏幕坐标，不改任何东西） |
| "现在大概是什么界面/什么状态" | eye_look | 300–450 token |
| "这个字太小/图标是亮是灰/勾没勾上" | eye_region | ≈370 token |
| "刚才那个弹窗写了什么/点了之后有反应吗" | eye_frames | ≈820 token |
| "刚才是哪一块在动"（不定点） | eye_window | 100 格≈540，16 格≈480 |
| "半小时前那个报错页长什么样" | eye_mem → eye_mem_get | 列表≈0，取一张≈300 |
| "我在不在录/眼睛开着吗" | eye_status | 0 |
| "就盯这个小面板/报错框" | 先 eye_focus 挪框，再取图 | 省一大截 |

口诀：**能读字就别取图；一屏看不清就凑近，不要用更宽的图硬看。** 图进上下文后每轮都会重读（缓存价约原价 1/10），"少而准"比"多而全"省得多。

## 1. 取图三档

### eye_look —— 一屏全景
- 参数：w 320–1280（默认 768）、q 40–90（默认 68）
- 拿环里最新一帧，等比缩到宽 w，重编 JPEG
- token ≈ 宽×高÷750：768→442、640→307、1280→1229
- 回答"大概什么界面"；**看不清小字**。降 q 只省流量不省 token，降 w 才省（平方关系）。

### eye_region —— 凑近 1:1
- 参数：fw 200–1600（默认 700）、fh 120–1200（默认 393）、cx/cy 裁剪中心、atCursor:true 裁在鼠标处
- 最新帧按原像素裁一块，**不缩放**，输出 PNG
- token ≈ 700×393→367
- 回答"这个字/这个图标/勾没勾上到底是什么"；坐标是屏幕物理像素，和 eye_find 返回的同一套。

### eye_frames —— 回看刚才
- 参数：span 往回几秒 1–60（默认 10）、n 抽几格 1–12（默认 6）、cols 1–6（默认 3）、w 480–1600（默认 1280）
- 从环里均匀抽帧拼联络表，每格左上角黑底黄字编号 0..n-1，**最后一格是现在**
- token ≈ 1280×480→819
- 坑：屏幕闲着时只有 2fps，抽出来会重复，"看起来没动"可能是采样假象；格子约 400×225，小字要再 eye_region/eye_cell；快速动画会漏帧。

### eye_focus —— 先把取景框挪过去（不是取图工具，但最省钱）
- 用法：eye_focus({title:"配置"}) / {hwnd:123} 绑窗口（跟着窗口走）；{x,y,w,h} 固定一块；{clear:true} 取消。
- **优先级：聚焦 > 跟随 > 框选 > 整屏**。所以"框一块"没生效，先看是不是还留着聚焦（eye_focus({clear:true}) 再试）。
- 定位顺序：eye_text（读前台窗口名，免费）→ eye_focus({title}) → 或 eye_find 拿坐标再给固定矩形。
- 挪完框后 eye_look / eye_region / eye_frames **自动只抓这块**：600×400 一块 = 320 token，1:1 原像素，小字比整屏缩图清楚。
- 换区域会清空内存环（帧数归零），不是坏。
- 一次任务结束就 clear，别锁在一个早没用的窗口上。

## 2. 余光拼图：看清"哪块在动"

- eye_window({span:10,n:16,cols:4}) → 10 秒 16 格拼图，每格约 200×123：能看出"这是窗口/这是面板/这是输入框"，**正文认不出**。
- 100 格（默认，每格约 80×50）：只能看出哪块在动，字完全糊。
- 拿到热格号后：eye_cell({i, span, n}) 回取那一格的 1:1（700×393≈370 token）；要原文先 eye_text。
- 规矩：拼图定位 → eye_cell 凑近 → 要文字就 eye_text。别拿拼图当"读字"用。

## 3. 留档：事后回看

- eye_mem({limit, since_min, before_min, q}) 列表：时间 + 窗口标题 + 变化分 + 编号（负数，-1 = 最新）；头行给"多少张/多少 MB/最老多久前/按现在设置最多能留多久"；尾行给翻页 before_min。
- eye_mem_get({i:-1}) 或 {ts:unix秒} 取那张（640 宽缩略，≈300 token）。
- 只存"变化够大"的帧、打过码、只有缩略；面板可关、可调张数（默认 600）/容量（默认 100MB）；**不按时间删**，能留多久由这两个参数算出来。
- 留档目录：插件目录下 archive/（面板有"打开文件夹"）。
- 用途："半小时前那个报错写的什么""下午是不是弹过一次窗"——环形缓冲只看 45 秒，留档看几十分钟。

## 4. 自动聚焦（设计定的降级链，按顺序走，不猜）

1. **提示词优先**（免费）：用户说了窗口名/按钮名 → eye_focus({title}) / eye_find({q}) / 直接用坐标。
2. **鼠标最近点击位置**（免费）：eye_timeline / eye_status 的 clicks、eye_echo 的前后帧 → 框在那附近。
3. **整屏看一眼定位**（≈690 token）：eye_look({w:960}) 专门用来找"问题在哪一块"，锁定后 eye_focus 挪框再 1:1 取。
4. 任何一步不成立 → 退回整屏，别硬猜。多显示器/缩放下先对齐坐标。

## 5. 标准套路

**看一个不熟界面**：eye_look → 发现要看细的地方 → eye_region({atCursor:true}) 或给 cx/cy → 需要原文再 eye_text。

**盯一个小面板**：eye_text/eye_focus 定位 → eye_focus 挪框 → eye_look（拿到这块 1:1，小字也清）→ 完事 clear。

**验收一次操作**：操作前 eye_look → 做动作 → eye_frames({span:10,n:6}) 看变化 → 可疑那格 eye_region 放大。

**读报错**：先 eye_text（免费）；读不到（自绘界面/图里的字）再 eye_region 裁报错框。

**坐标从哪来**：eye_find 给中心点；eye_status 给光标；eye_echo 给最近点击前后；真要点用 win32 那套工具，别用眼。

## 6. 会被拒的情况（被拒不生成图、不扣 token）

| 返回 | 原因 | 怎么办 |
|---|---|---|
| 视觉取图关着（只读字、不出图） | 视觉开关关了 | eye_vision({on:true}) |
| 今天的看图预算用完了… | 当日额度用尽 | 提额度 eye_vision({budget:600000})，或改用 eye_text |
| 眼睛是关着的（采集进程没起） | 采集进程没起 | eye_toggle({on:true})，等约 2 秒 |
| （拿到图了，但宿主没有 attachments 服务…） | 宿主不支持附件 | 只能读字；这条提示本身就是证据 |
| 返回 images 但你看不到图 | 插件 < 0.3.1 或宿主没转附件 | 升级；判定标准是"对话里真的出现那张图" |

## 7. 隐私与开关

- eye_mask({rects}) 框住的地方在**进缓冲之前**就糊：既不出图、eye_text 也不读那里的字。银行/支付/密码类窗口按标题自动整窗糊。
- eye_toggle({on:false}) 是真把采集进程杀掉，不是只藏窗口。
- 主动看一眼那一帧会成为对话附件存在本机；环形缓冲不写盘。留档只写缩略图、打过码、在插件目录里，可关可清。
- 输出走本地 HTTP（127.0.0.1:13201），不上传任何服务器。

## 8. 成本控制

- 单张 token ≈ 像素 ÷ 750；**文件大小（JPEG 质量）不影响 token**。面板"视觉"节能看用量/改额度/清零，eye_vision() 也能查。
- 想省：eye_text → 目标明确先 eye_focus 只抓那块 → 640 宽 eye_look → 只放大可疑那一块 → 回看用 n=4 不用 12 → 拼图用 16 格不用 100 格。
- 一次任务里反复看同一屏没意义：看一次，记住结论。

## 9. 不该做的

- 不拿图去读小字（该用 eye_text）；不拿整屏缩图硬抠细节（该 eye_region 或先 focus）。
- 不连着截好几张"看看有什么变化"——先想清楚要回答什么。
- 不用眼睛去点/操作任何东西：它只报坐标。真要动手走 win32 或 gui 那套。
- 不在用户明确说了"别录/别看"时取图；敏感窗口先 eye_mask。
- 不假装看见：没取图就说没看，取图失败就说失败，不编画面内容。
- 不把留档当"监控"：它是给我事后回看的，不是盯人用的。
